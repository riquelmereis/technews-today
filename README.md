# 🚀 TechNews Today — Portal de Notícias de Tecnologia

Um portal moderno de notícias sobre tecnologia desenvolvido exclusivamente com **HTML5 semântico** e **CSS3**, sem uso de frameworks ou JavaScript. O projeto foca em estilização avançada com tema escuro (Dark Mode), layout responsivo e novos recursos modernos do CSS.

---

## 📌 Demonstração e Recursos

- 📑 **HTML Semântico:** Estruturação limpa utilizando `<header>`, `<main>`, `<article>`, `<section>` e `<footer>`.
- 🪟 **Efeito Glassmorphism:** Header fixo no topo (`position: sticky`) com fundo em vidro fosco (`backdrop-filter`).
- 🎨 **Estilização Moderna:** Título com efeito gradiente no texto.
- 📐 **Layout com CSS Grid:** Organização dos elementos em grade (vídeo e newsletter lado a lado).
- 🔽 **Elemento Retrátil Sem JS:** Seção "Leia mais" criada nativamente utilizando as tags `<details>` e `<summary>`.
- 📱 **Design Responsivo:** Adaptado para telas de celular utilizando *Media Queries*.
- 📋 **Formulário com Validação Nativa:** Newsletter com validação automática do navegador nos campos de formulário.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3** (Grid, Flexbox, Media Queries, Backdrop Filter)
