# 🚀 TechNews Today — Portal de Notícias de Tecnologia

Um portal moderno de notícias sobre tecnologia desenvolvido exclusivamente com **HTML5 semântico** e **CSS3**, sem uso de frameworks ou JavaScript[cite: 1, 2]. O projeto foca em estilização avançada com tema escuro (Dark Mode), layout responsivo e novos recursos modernos do CSS[cite: 1, 2].

---

## 📌 Demonstração e Recursos

- 📑 **HTML Semântico:** Estruturação limpa utilizando `<header>`, `<main>`, `<article>`, `<section>` e `<footer>`[cite: 2].
- 🪟 **Efeito Glassmorphism:** Header fixo no topo (`position: sticky`) com fundo em vidro fosco (`backdrop-filter`)[cite: 1].
- 🎨 **Estilização Moderna:** Título com efeito gradiente no texto[cite: 1].
- 📐 **Layout com CSS Grid:** Organização dos elementos em grade (vídeo e newsletter lado a lado)[cite: 1].
- 🔽 **Elemento Retrátil Sem JS:** Seção "Leia mais" criada nativamente utilizando as tags `<details>` e `<summary>`[cite: 2].
- 📱 **Design Responsivo:** Adaptado para telas de celular utilizando *Media Queries*[cite: 1].
- 📋 **Formulário com Validação Nativa:** Newsletter com validação automática do navegador nos campos de formulário[cite: 2].

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**[cite: 2]
- **CSS3** (Grid, Flexbox, Media Queries, Backdrop Filter)[cite: 1]
